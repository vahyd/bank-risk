# Bank Risk Dashboard

Enterprise Banking Risk Management and AI Intelligence Dashboard built with Streamlit.

## Modules

- **Executive Overview** — High-level risk summary
- **Credit Risk** — Loan portfolio credit analysis
- **Concentration Risk** — Portfolio concentration metrics
- **Risk-Adjusted Performance** — RAROC, Sharpe, risk/return
- **Sector & Market Risk** — Market exposure by sector
- **Macroeconomic** — Macro stress indicators
- **Liquidity & Funding** — Liquidity risk metrics
- **Capital Adequacy** — Capital ratios & buffers
- **Stress Testing** — Scenario-based stress tests
- **AI Early Warning** — ML-driven risk signals

## Setup

```bash
pip install -r requirements.txt
streamlit run app/main.py
```

## Requires

Python >= 3.10
